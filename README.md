# දින චර්යා

දිනපතා පුරුදු, භාවනාව සහ ඉතිරි කිරීම් සටහන් තබාගන්නා ඇප් එකක්.
එක පාරක් විවෘත කළාට පස්සේ **ඩේටා නැතුව, airplane mode එකේ වුණත්** වැඩ කරනවා.

## 1. GitHub එකට දාන එක

1. [github.com](https://github.com) එකට ගිහින් ලොග් වෙන්න.
2. දකුණු උඩ **+** → **New repository**.
3. නමක් දෙන්න — උදා: `dina-charya`
4. **Public** තෝරන්න. (Private නම් Pages එක free නෑ.)
5. **Create repository** එබන්න.
6. **Add file** → **Upload files** → උඩ තියෙන ෆයිල් හයම එකවර දාන්න.
7. පහළ **Commit changes** එබන්න.

> ෆෝන් එකෙන් කරනවා නම්: text ෆයිල් තුන (`index.html`, `sw.js`, `manifest.webmanifest`)
> **Add file → Create new file** එකෙන් නම දාලා, පෙළ අලවලා හදන්න පුළුවන්.
> PNG තුන නම් **Upload files** එකෙන්ම දාන්න වෙනවා.

## 2. Pages එක ඔන් කරන එක

1. Repository එකේ **Settings**.
2. වම් පැත්තේ **Pages**.
3. *Source* යටතේ **Deploy from a branch**.
4. *Branch* → **main**, folder → **/ (root)** → **Save**.
5. විනාඩි 1–2ක් ඉන්න. පිටුව refresh කරාම ලින්ක් එකක් එනවා:

```
https://ඔයාගේ-නම.github.io/dina-charya/
```

ඒක තමයි ඔයාගේ ඇප් එකේ ලිපිනය.

## 3. ෆෝන් එකට එකතු කරන එක

**Android (Chrome):** ලින්ක් එක විවෘත කරලා → උඩ දකුණේ **⋮** → **Add to Home screen** / **Install app**.

**iPhone (Safari):** ලින්ක් එක විවෘත කරලා → පහළ **Share** ⬆️ → **Add to Home Screen**.
*(iPhone එකේ Chrome නෙවෙයි, **Safari** එකෙන්ම කරන්න ඕන.)*

සියලු දත්ත **ඔයාගේ ෆෝන් එකේ විතරයි** තියෙන්නේ. කිසිම server එකකට යන්නේ නෑ.
ඒක හොඳයි — ඒත් අවදානමකුත් තියෙනවා: **browser data මැකුවොත් දත්ත යනවා.**

ඒ නිසා මාසෙකට වතාවක් හරි:

2. **පිටපත් කරන්න** එබන්න
3. ඒ පෙළ WhatsApp එකේ ඔයාටම යවලා හරි, Notes එකක හරි තියාගන්න

## පස්සේ ඇප් එක වෙනස් කරාම

`sw.js` ෆයිල් එකේ මුලින්ම තියෙන මේ පේළිය වෙනස් කරන්න:

```js
var CACHE = 'dina-charya-v2';   // → 'dina-charya-v3'
```

මේක වෙනස් නොකළොත් ෆෝන් එකේ පරණ එකම තියෙනවා, අලුත් එක එන්නේ නෑ.

## දැනගන්න හොඳ දේවල්

- Service worker එකට **https** ඕන. GitHub Pages එකේ ඒක තියෙනවා, ඒත් ෆයිල් එක කෙලින්ම
  (`file://`) විවෘත කරොත් offline කොටස වැඩ කරන්නේ නෑ.
- භාවනා ගෙඩියේ හඬට ෆෝන් එකේ **silent mode එක ඕෆ්** කරන්න ඕන.
- සිංහල අකුරු ෆෝන් එකේ තියෙන font එකෙන් තමයි පෙන්නන්නේ — වෙන තැනකින් බාගන්නේ නෑ.
  offline වැඩ කරන්නේ ඒ නිසා.
